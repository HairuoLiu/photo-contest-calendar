# 设计文档 · Design Notes

本站的视觉与交互设计思路。技术实现见 [`TECH_DOC.md`](./TECH_DOC.md)；用户指南见 [`README.md`](../README.md)。

## 设计理念
摆脱「量产模板感」，营造画廊 / 画册般的艺术气息（quiet luxury）：克制的色彩、衬线展示标题、暗房肌理，把注意力还给日历本身。设计评审由具 10 年手机端经验的红点 / iF 视角把关，核心原则是一致的交互语言与「一眼可见信息密度」。

## 视觉系统
- **字体**：真正加载 **Inter**（界面）+ **Fraunces**（西文展示标题）+ **思源宋体 / Source Han Serif**（中文展示标题），关键标题用衬线体呈现画册气质。
- **胶片颗粒 + 暖调**：全站叠加一层极淡的 `feTurbulence` �噪点（暗房 / 画册肌理），配「暖纸 / 暖墨」底色替代冷冰冰的 slate；四角轻微暗角把视线引向中央日历。
- **收橙（quiet luxury）**：品牌橙 `#f97316` 只保留给「今天 / 品牌标识 / 激活视图」，其余强调改用中性墨与靛蓝，避免满屏橙色。
- **分类去噪**：12 色「彩虹仪表盘」改为中性 chip + 低饱和圆点，降低信息噪音。
- **图标化**：emoji（📸 / 🎉 / 📭 / 国旗）全部换成 [Lucide](https://lucide.dev/) 线性图标，跨平台一致。
- **动画令牌**：全局缓动 / 时长集中在 `src/index.css` 的 CSS 变量（`--dur-fast/mid/slow`、`--ease-out/in-out`），数字用 `tabular-nums` 对齐。

## 交互设计
- **视图控制紧贴日历**：年 / 月 / 周切换与「今天 / 上 / 下」导航移到「本周 / 本月截止」面板下方、日历上方，不再与面板混排。
- **桌面悬停气泡**：鼠标移到某天，浮动气泡跟随展示当天赛事（用 `useSpring` 拖尾缓动），并就地高亮该日格。
- **手机端日格底部弹层（DaySheet）**：月视图点任意一天，从底部滑出抽屉列出当天赛事；遮罩点击 / 下滑关闭；安全区适配。这是悬停气泡在触控端的等价交互。
- **周 / 年视图**：周视图呈本周投稿截止一览；年视图用 12 个迷你月历 + 截止日圆点总览全年。

## 移动端设计考量
- 日格**始终显示「N 场」**，无需点进去才知道有没有内容。
- 「今天」加呼吸环（`today-pulse`）动画。
- 底部弹层带 `safe-area` 适配，关闭按钮与卡片操作区满足拇指热区（≥ 44px）。
- mobile-first 响应式，手机 / 平板 / 桌面共用一套布局。

## 多语言（规划）
最小化语言切换控件（详见下文评审要点）：右上角小地球图标 + 当前语言码（如 `EN` / `中`），点击展开语言列表；列表可长（内部字典），但触发控件保持极小。仅翻译 UI 文案，赛事名称作为专有名词保留原文。

## 评审要点（红点评委摘要）
- 桌面「悬停预览」与触控「底部弹层」是**同一意图的两种形态**，这是核心交互统一原则。
- 信息密度优先保证「一眼看见当天有几场」，再谈细节。
- 语言切换等辅助控件须遵循「小但可发现」：极小触发 + 明确可点击反馈（hover / 按压 / focus ring），绝不靠面积博存在感。
- 待评估的「艺术豪赌」项（暂未实现）：自定义光标、真实摄影 hero / 封面、视图间共享元素过渡。
